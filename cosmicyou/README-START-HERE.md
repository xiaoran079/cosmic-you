# Cosmic You — website + editable blog

This package preserves the existing Cosmic You interactive astrology site and adds **The Cosmic Journal** at `/blog/` with 3 original sample posts. The visual design is built with CSS gradients and stars; it does not copy artwork from a third-party site.

## Try it locally

Open a terminal in this folder and run `python -m http.server 8000`. Visit `http://localhost:8000/blog/`. A simple file double-click will NOT load blog posts because browsers block local `fetch` requests.

## Publish the site

1. Create a GitHub repository and upload all the files in this folder, including `.github` and `scripts`.
2. In Netlify, import that GitHub repository as a new site (do not use one-off drag-and-drop deployment for CMS updates). The `netlify.toml` build command updates `blog/posts.json` and publishes the repository root.
3. Test the public homepage and `/blog/`.
4. Update `/admin/config.yml`: change `OWNER/REPO` to your GitHub repository and change both site URLs.
5. **Authentication is a separate setup step**: Decap's GitHub backend requires a working GitHub OAuth authorization service (or a supported Git Gateway/Identity installation). A fresh Netlify site does not automatically provide one. Configure a trusted OAuth service and set `base_url` and `auth_endpoint` in the CMS config according to that service's documentation. Until then `/admin/` is only a placeholder login screen, NOT a functional editing dashboard. Never put GitHub client secrets in the website files.
6. Grant collaborators appropriate repository access, then test creating a draft and publishing an article. A GitHub Actions workflow updates the article index after CMS commits; Netlify rebuilds from GitHub.

## Blog content and edits

Articles are Markdown files in `blog/posts/` with title, category, date, excerpt, optional cover, and draft flag. The blog index is regenerated by `scripts/build_index.py`. For a manual test before CMS login is configured, edit or add an article, run that script, and push changes to GitHub.

## Important limitations

- Weekly horoscope email delivery is NOT connected. Do not advertise it as working.
- Natal chart calculations and city lookup rely on external browser libraries/services; test them on the deployed site.
- The birth details form collects sensitive personal information; add an appropriate privacy notice and verify handling before public marketing.
- Birth-time-unknown charts cannot reliably show an ascendant.
- Astro interpretations and compatibility scores are entertainment, not scientific predictions.
- This package has been checked for file structure and code syntax, but the CMS authentication and live deployment have not been tested.
